# デザイン見本（Issue #94）

実装前に方向を判断できるよう、承認済みの見本をリポジトリ内へ写した。
ブラウザでは `/design-direction` を開く。

## 合意した方向

- 主役の色は既存の緑（`--accent: #1a7f5a`）を育てる
- Issue Tracker の分かりやすさは残しつつ、ID や等幅書体の出し過ぎはやめて親しみやすくする
- 外部素材はトップページのヒーロー 1 箇所に限る
- 詳細ページでは投稿写真を主役にし、飾り画像と競合させない
- 日時は人間の時間感覚（例: `2 時間前`）で読ませる

## 見本に含める画面

1. トップページ
2. Issue 一覧
3. Issue 詳細（写真あり）
4. Issue 詳細（写真なし）

加えて、空の状態（Issue 0 件 / コメント 0 件 / 検索結果 0 件）と、読み込み中の見せ方も同じページに置く。

## 見出しの段階

5 段階へ畳まず、見出し専用に 3 段階を残す。

- `--text-heading-page`
- `--text-heading-section`
- `--text-heading-site`

変更する既存値は 1 つだけで、`--text-heading-site` を `1.2rem` から `1.0625rem` へ下げる。
サイト名は本文より大きい必要がなく、狭い画面でヘッダが崩れる一因でもあるため。

## 空の状態・待ち時間

- **Issue 0 件**: 「最初の 1 件が基準になる」と伝え、起票ボタンを主役にする
- **コメント 0 件**: 「まだコメントなし」で終わらせず、何を書くと次の人が動きやすいかを添える
- **検索結果 0 件**: フィルタを広げる導線を同じ面の中に置く
- **読み込み中 / 送信中**: 文言だけ変えず、骨組みと押せないボタンの面で処理中だと分かるようにする
