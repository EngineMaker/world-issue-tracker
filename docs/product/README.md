# プロダクト議論の記録

World Issue Tracker の方針を決めるためにまとめた資料。実装の手順書ではなく、
**「何を作るか／なぜそう決めたか」の記録**を置く場所。

もともと [loop-engineering](https://github.com/mktoho12/loop-engineering)
リポジトリに置かれていたが、内容は WIT 固有のプロダクト判断であり、
ループエンジニアリングの方法論とは無関係のため、こちらへ移した。

| ファイル | 内容 |
| --- | --- |
| `question-to-founder.md` / `.html` | 想定利用者を確定するための発起人への質問。デザインの判断基準を決める前提 |
| `discussion-2026-08-07.md` | `needs-discussion` 5件の論点整理（2026-08-07 時点） |
| `discussion-2026-08-18.md` | 同上（2026-08-18 時点）。地図・写真・多言語・ORM の方針 |
| `round1-spec.md` | `DELETE /issues/:id` の仕様書。ループ実験の初回入力として書かれたもの（歴史的資料） |

デザイン関連の資料は一つ上の `docs/` にある（`design-direction.md`,
`design-mockup-2026-08.html`, `visual-check.md`）。
